## LinkedIn post - English
I've been working on Morvarid, a Persian-language Telegram support bot for a demo computer-accessories store.

Starting from an educational bot template, I customized the catalog, store knowledge and brand voice, including prompt-guided product recommendations based on budget and device compatibility questions.

The prototype includes optional voice replies, sample order tracking, short conversation history and human support handoff. I also prepared 24 challenging customer scenarios and offline checks for the knowledge, order and audio helpers.

This project helped me practice API integration, structured JSON data, prompt design and testing the boundaries of an AI support workflow. Store data is synthetic; authenticated order access and production deployment are future work.

## متن پست لینکدین - فارسی
روی «مروارید»، یک نمونه پشتیبان هوشمند فارسی در تلگرام برای فروشگاه لوازم کامپیوتر، کار کرده‌ام.

این پروژه را بر پایه یک قالب آموزشی شخصی‌سازی کردم: کاتالوگ ۱۰ محصول، دانش فروشگاه، ۳۰ سؤال واقع‌گرایانه و پرامپت متناسب با برند. ربات درباره محصولات پاسخ می‌دهد، برای انتخاب بر اساس بودجه و سازگاری سؤال می‌پرسد، سفارش‌های نمونه را پیگیری می‌کند و پاسخ صوتی می‌فرستد. مسیر ارجاع به پشتیبان انسانی هم دارد.

برای بررسی کیفیت، ۲۴ سناریوی مشتری سختگیر آماده کردم و تست‌های آفلاین خواندن داده، جست‌وجوی سفارش، ساخت پرامپت و تبدیل صدا را اضافه کردم.

تمرکز این تمرین روی اتصال APIها، داده JSON، طراحی پرامپت و شناخت محدودیت‌های دستیار هوشمند بود. داده‌ها آزمایشی‌اند؛ احراز هویت سفارش و آماده‌سازی برای استفاده واقعی از قدم‌های بعدی‌اند.
